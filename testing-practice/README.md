# Testing practice

A small, fast project for practising xUnit tests, separate from the Aspire mock test. No Docker needed.

| Project | What it is |
|---|---|
| `Practice.Core` | Small classes to unit test. Some have bugs |
| `Practice.Api` | A tiny Minimal API for integration tests with `WebApplicationFactory` |
| `Practice.Tests` | Your tests. One finished example is included |

Open `src/Practice.sln` and start with [`EXERCISES.md`](EXERCISES.md).
